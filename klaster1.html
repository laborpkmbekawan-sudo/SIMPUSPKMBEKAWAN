Perencanaan (RUK/RPK)
Input RUK/RPK, tracking realisasi kegiatan, kalender kegiatan, dan upload dokumen SK/SOP — segera dibangun.
💰
Keuangan
Input anggaran per sumber dana (BOK/JKN/APBD), transaksi harian, realisasi anggaran, rekonsiliasi kas — segera dibangun.
🧑‍⚕️
Kepegawaian (SDM)
Database nakes lengkap (STR/SIP), reminder jatuh tempo, riwayat diklat, penilaian kinerja — segera dibangun. Data akun dasar sudah bisa dikelola di menu Manajemen User & Akses.
🛠
Sarpras & Alat (ASPAK)
Database alat kesehatan, jadwal kalibrasi & pemeliharaan, riwayat kerusakan/perbaikan, stok sarana non-alkes — segera dibangun.
✚
Mutu & Keselamatan Pasien
Indikator Mutu (INM), Insiden Keselamatan Pasien (IKP), PPI, K3, MFK, audit internal, manajemen risiko — segera dibangun di level manajemen. Sebagian (medication error/FMEA) sudah ada di Apotek → Laporan → Keselamatan Pasien.
🌐
Jejaring & Jaringan
Data Pustu/Poskesdes/Posyandu, jadwal pembinaan teknis, laporan hasil pembinaan, kinerja jejaring — segera dibangun.
▦
Laporan Internal
Rekap realisasi anggaran, rekap kepegawaian, rekap sarpras/ASPAK, rekap indikator mutu — segera dibangun.
📤
Laporan ke Dinas Kesehatan
Laporan Kinerja Puskesmas (PKP), Laporan INM, Laporan IKP, Rekap Gabungan LB1–LB4 (SP2TP), Laporan Realisasi Anggaran — segera dibangun.
🛡
Audit / Keamanan
Log aktivitas user, log akses data keuangan, log akses data kepegawaian, monitoring kepatuhan dokumentasi mutu — segera dibangun. Log sesi aktif (paksa logout) sudah jalan lewat tabel sesi_aktif.
